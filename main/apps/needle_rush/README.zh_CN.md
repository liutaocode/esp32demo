# 再插一针

适合 AI Passport 的中文单键反应小游戏：把针插进旋转圆盘的空隙，避开已有的针，
连过十关，或者重玩同题刷新分数。界面使用简体中文；下图由实际 LVGL 页面在
模拟硬件环境中渲染，并非设备实拍。



## 玩法

| 页面 | 上键 | 下键 | 确定键 |
| --- | --- | --- | --- |
| 开始页 | 切换难度 | 切换难度 | 开始 |
| 游戏中 | 暂停 | 无操作 | 发射 |
| 暂停中 | 继续 | 返回开始页 | 无操作 |
| 结果页 | 开始下一个题号 | 返回开始页 | 同题重玩 |

长按确定返回开始页。发射在按下时触发；继续按住同一次按键，会在长按事件到来时
返回开始页。圆盘下方的橙点和虚线标明发射位置，圆盘中心数字表示剩余针数。
深色针是障碍，绿色针是已成功插入的针；碰撞的针会变红。每过一关，转向反转且速度增加。

- 轻松模式全局共三次机会，高手模式只有一次。
- 每插中一针得 10 分，每连续插中三针额外加 5 分；失误会中断连击。
  十关共 62 针，全程无失误可得 720 分。
- 相同题号复现起始位置和各关速度。与朋友比较时，难度和题号都需要一致。
- 两种难度分别保留本次开机最高分，返回页面不会丢失，重启后清空。
  不需要账号、网络，不保存个人信息，不使用 TTS。
- 闲置一分钟自动暂停并调暗，三分钟关闭背光。熄屏后第一次按键只唤醒，
  再按上键继续。

## 构建与验证

激活 ESP-IDF 5.5.3 后，在仓库根目录运行：

```bash
FAP_APP=needle_rush ./tools/validate.sh
```

经过校验的合并固件位于 `build/FoloToy-AI-Passport-full.bin`。构建只选择本应用，
保留 3 MB 应用上限、受保护的设备身份、永久 Recovery 和上键五秒引导入口。
使用现有小程序 Recovery 流程安装，详见
[兼容性说明](../../../docs/development/engineering/ble-recovery-compatibility.zh_CN.md)。

静态门禁已接入纯 C 状态测试：角度环绕、精确碰撞边界、飞行中暂停、无效输入、
卡顿计时、纪录保留、同题重玩，以及 200 局完整通关。另有实际 LVGL 页面测试，
检查字形覆盖、拒绝英文单词、验证文字边界与 3600 组圆盘布局，并覆盖唤醒、
连续输入、降级显示和 50 次退出重进：

```bash
cmake -S tests/needle_rush_ui -B build/needle-rush-ui -G Ninja
cmake --build build/needle-rush-ui
(cd build/needle-rush-ui && ./preview)
python3 tools/generate_needle_rush_font.py
```

预览测试在工作目录输出 PPM 截图，需要 `managed_components/` 中已解析的 LVGL。
字体生成器使用组件自带的思源黑体和固定版本 `lv_font_conv@1.5.3`，生成未压缩的
16 像素中文子集，数字回退到 Montserrat。

## 运行方式与设备验收

纯状态模块负责碰撞和计分；按键回调只投递带时间戳的事件。
LVGL 定时器负责运动和绘制，进入及退出页面需要 BSP 的 LVGL 锁。
删除页面前先停止定时器，不额外创建应用工作任务、网络客户端、图像解码器或音频缓冲区。

发射后的 120 毫秒飞行和 420 毫秒反馈期间，圆盘保持静止，碰撞以收到按键时
显示的位置判定。每帧最多处理一个排队事件，超过 200 毫秒的旧事件丢弃。
卡顿时一帧最多推进 60 毫秒游戏时间，闲置计时仍使用实际时间。
电量只在开始、暂停和结果页面读取。

编译与主机渲染无法代替真实屏幕和按键延迟验证。设备上需检查最高速度下两种转向、
擦边碰撞、连续按键与长按返回、中文显示、背光唤醒和 Recovery 入口。
实际帧率、功耗与按键手感仍需设备测量。
