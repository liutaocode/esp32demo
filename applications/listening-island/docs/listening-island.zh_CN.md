# 英语磨耳朵：设计与操作

## 体验

把零碎时间变成轻松听英语的时间。八座岛每座 48 句原创短句，覆盖家庭、饮食、校园、动物、运动、天气、出行和睡前表达。难度约为小学阶段；这是原创练习集，不宣称对齐某本教材，也不宣称已测得学习效果。菜单和操作提示保持中文。随身听和答题反馈同时显示英文原句及中文译文；寻宝出题时隐藏英文，答题后再揭晓。英语也会通过合成语音播放。

耐玩思路是可选的短互动与收集进度：随身听可以不看屏幕，寻宝每轮只做八题。不用连续签到、不收费、不需要麦克风或网络，答题也不倒计时。商业热度尚未验证。

## 操作

| 页面 | 上 / 下键 | 确定键 | 长按上键 | 长按确定 |
| --- | --- | --- | --- | --- |
| 首页 | 选择五个入口 | 进入 | 无操作 | 留在首页 |
| 选岛 / 印章 | 上一座 / 下一座岛 | 开始 / 返回 | 无操作 | 首页 |
| 随身听 | 上一句 / 下一句 | 暂停 / 从句首继续 | 重听 | 回首页并停止 |
| 寻宝答题 | 选择第一 / 第二个中文含义 | 提交 | 重听英语 | 回首页并停止 |
| 答题反馈 | 重听正确句子 | 下一题 | 重听 | 回首页并停止 |

随身听每句完整播放两遍，中间间隔 800 毫秒，再留 2.5 秒跟读。播完所选集合，或者达到 5/10/15 分钟定时后停止；暂停时定时仍继续。不后台录音、不做语音识别，也不会给出虚构的发音评分。

寻宝在选中主题抽取八个不重复句子，随机安排两个答案的位置，有错题时优先带上一道旧错题。答对会从错题集合移除该句；答错展示正确译文并加入回听。仅重听不会清除错题。答对六、七、八题分别获得一、二、三枚印章，每座岛保留最好成绩。

## 实现与存储

纯状态逻辑位于 `main/apps/listening/listening_state.c`。实际 LVGL 界面与唯一音频及存储工作任务分离。按键回调只向有界队列投递事件，页面变化由 LVGL 定时器处理，电量由主任务在 LVGL 之外读取。音频请求使用递增编号，每 512 个采样检查取消，旧播放完成不能推进新句子。解码循环只用 1024 字节 PCM 和 256 字节压缩缓冲。

语音使用 16 kHz 单声道 IMA ADPCM，重听和不同玩法复用同一份片段。首个音频包最多使用应用空间的 1,600,000 字节，第二个使用 `0x360000` 起、大小 `0x3A0000` 的新增数据分区。应用仍小于 3 MB，`0x356000` 身份区、`0x700000` Recovery 和上键五秒恢复入口保持不变。启动时验证资源 CRC 后才启用声音，构建门禁验证合并镜像确实包含资源。最终清单记录实测体积和时长；优先存完整自然短句和更多素材，减少装饰位图占用。

进度使用独立 `listen_island` NVS 命名空间、带版本的数据块、数值范围校验和明确的保存错误提示。旧版本音量自动迁移为新的五档（20/40/60/80/100，默认 60），保留听过的句子、错题和印章。初始化失败不会擦除其他应用数据。突然断电若发生在队列落盘之前，可能丢失最后一次变化。声音不可用时不能提交答题，电量不可读显示占位符，只有播放完成才记为已听。服务及唯一屏幕随应用存活到关机，不存在删页后工作任务继续访问界面的情况。运行时也提供取消及退出确认接口。

## 构建与验证

```bash
source /path/to/esp-idf-v5.5.3/export.sh
./tools/validate.sh
```

完整门禁检查仓库规则、生成资源、纯状态逻辑、全部压缩音频、每句译文的实际 LVGL 字形和边界、基线主机测试、固件构建、恢复兼容性及合并资源。不会打开串口或安装固件。

重新生成语音需要安装 `kokoro`、PyTorch、NumPy、SoundFile 的 Python 环境及 FFmpeg：`python tools/generate_listening_audio.py --synthesize`，已有 WAV 会复用。字体使用 `python tools/generate_listening_fonts.py`。模型与声音来源见[素材记录](../assets/music/listening/README.zh_CN.md)。

## 获得安装授权后的实机检查

1. 使用导出的分段固件或小程序 Recovery 安装，绝不能从零地址整包覆盖已有身份的设备。
2. 检查启动、中文字形、电量、实体短按与长按、标题和底栏边界。
3. 抽听两个音频包及八个主题，确认发音、语速、句尾完整性、底噪、切换杂音和舒适音量。
4. 快速切歌、暂停、重听、回首页、换模式，确认旧声音不能推进新题目。
5. 验证错题回听、印章、重启保存、突然断电和资源异常处理。
6. 跑完完整主题及每档定时，观察堆内存、长时间响应、扬声器和外壳状态。
7. 实机确认上键五秒 Recovery 入口及小程序安装兼容性。
8. 获取新鲜串口画面及对应凭证，再制作最终竖版封面与提交预览。

构建成功和电脑渲染不代表上述硬件项目通过。
