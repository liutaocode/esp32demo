# 注意力小邮差实现说明

一个离线中文按键小游戏：看见目标时送信，其他客人出现时忍住不按。带图介绍与审核准备见项目文件夹。

## 交互

上下键选择四秒、三秒或两秒的客人停留时间。确定先开始两步不计分练习：送信练习不限时，等待练习采用所选节奏。练错会重试当前步骤。正式游戏前展示规则卡；目标整局固定且一直可见。每页只留一条简短主要提示与大动物图；十二个小格代替文字题号。练习直接演示按键和等待，正式游戏提示“一样才按”。每局六位目标、六位其他客人，分成两个平衡的半局后随机排列。每位客人出现前有 850 毫秒松手间隔。见目标按确定，其他客人等时间条结束；每次反馈都等确定再继续，不自动推进。十二位客人结束后，分别展示送对与等对次数，各以六次为满值。

下键暂停，确定先展示 850 毫秒松手提示，再按原剩余时间继续；暂停页下键回首页。长按确定回首页。按下事件先于长按事件，所以长按可能先回答当前客人，再返回首页并放弃本局。结果页确定回家休息，上键重练同题，下键换新题并先提醒规则。首页进入始终先练习。没有最高分排名、永久档案、联网、麦克风、语音或奖励货币。同题重练保留题目种子和目标，重启清空本次会话。

## 运行与资源选择

应用与纯状态机位于本目录，不改变 BSP 或分区。界面沿用蓝天、标题牌、草地与描边面板；复用“刚才哪只”中三种可区分的像素动物，通过整数缩放矩形放大。目标用小头像和名字提示，客人用大图展示。主要提示采用 24 像素思源黑体子集，次要按键提示采用 16 像素子集，两套均包含数字与标点。电量放在右上云朵下方；读取不可用显示 `--%`。

按键回调只向四项静态队列发送带时间戳的输入，20 毫秒 LVGL 定时器负责状态和界面。丢弃超过 250 毫秒的旧输入及转场重复按键。截止时刻按输入时间判断；显示延迟不会压缩新客人的完整反应窗口。不处理连发事件。先停止定时器再删除屏幕，静态队列在页面生命周期之间保留。进入与退出由调用方持有 LVGL 锁。活跃游戏 30 秒无输入自动暂停；60 秒调暗，180 秒熄屏，唤醒的第一次按键不作答。不写 NVS，不访问音频，不新增图像帧缓冲或音频缓冲。

## 构建与检查

```bash
python3 tools/generate_focus_post_font.py
cc -std=c11 -Wall -Wextra -Werror -Imain/apps/focus_post \
  tests/test_focus_post_state.c main/apps/focus_post/focus_post_state.c \
  -o /tmp/focus-post-state
/tmp/focus-post-state
cmake -S tests/focus_post_ui -B /tmp/focus-post-ui-build
cmake --build /tmp/focus-post-ui-build -j8
mkdir -p /tmp/focus-post-previews
(cd /tmp/focus-post-previews && /tmp/focus-post-ui-build/preview)
python3 tools/render_focus_post_preview.py
# 先激活 ESP-IDF 5.5.3；以下仅构建，不安装：
FAP_APP=focus_post ./tools/validate.sh
```

状态测试覆盖三千组平衡题目、所有节奏、同题重练、练习纠错、计时边界、暂停与一直按或一直等的策略。生产界面 LVGL 本机测试覆盖所有页面、字形完整性、无拉丁字母界面、文字溢出、同级文字重叠、面板边界、过期输入、重复输入、休眠唤醒、按键不可用与五十次进出。预览模拟外设；真实显示与实体按键要等授权安装后验证。保留公共截图协议与永久 Recovery 契约。
