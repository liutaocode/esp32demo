# 深夜来电

一款由三通深夜电话串起的口袋悬疑游戏。你是还在接电话的那个人：
帮助被困车站的乘客，找回停电档案馆里的录音，再查清最后一通电话为什么显示自己的号码。

## 怎么玩

- 短按上／下键：在两个回应之间选择；短按确定键：作出回应。
- 长按上键：重听当前普通话对白。
- 长按下键：切换静音；所有对白都有完整中文字幕。
- 通话中长按确定：暂停，可继续通话或回到值班室。
- 值班室用上／下键轮换：继续通话、接通新来电、回声档案、声音设置、操作说明。
- 三分钟没有操作且语音结束后息屏。第一次短按或长按只唤醒，不会误选回应。

包含三章故事、22 个对话节点、六条可收集线索、七个结局。隐藏终章需要先完成前两章的真实救援。
所有章节从一开始就能进入；选择没有倒计时，可以折返重新核对证据。
结局会提示下次可探索的方向，档案会隐藏尚未解锁的结局，避免提前剧透。

每次回应都会排队保存。请等“正在保存”提示消失后再关机。
保存成功后，最近一次通话、线索、结局和音量都能跨重启保留。
接通另一章会替换当前通话，已收集线索与结局不变。读写异常会在界面中提示，
不会清空其他应用的存储空间。

界面全中文，内置 29 段离线普通话 TTS 对白。玩家用实体按键回应；
无需语音识别、麦克风录音、账号或网络。

## 构建与审核准备

本目录是 `feature/night-call` 分支的独立工作区，默认直接构建深夜来电，
无需额外选择应用，不影响父目录中的其他应用。

使用 ESP-IDF 5.5.3，参照[环境指南](docs/development/engineering/environment-setup.zh_CN.md)。
