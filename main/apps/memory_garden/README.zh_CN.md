# 天天记一记（Daily Memory）



天天记一记面向关注中老年记忆力衰退预防的用户，用轻松的看图、记顺序和家庭互动，
鼓励养成日常用脑习惯。本应用尚无临床证据证明能够预防或延缓记忆力衰退。

这是一款适合中老年人与家人一起玩的温和离线记忆游戏。三轮游戏会依次展示一组
带有明确名称的花园卡片，玩家按顺序回忆卡片，并在过程中种出一座适合拍照分享的
像素花园。

游戏用鼓励式反馈代替失败页：没有答对的卡片会立即再次显示，结果页同时记录“花朵”
和“新芽”。应用不保存答案或健康数据，不需要账号、手机或网络。

## 玩法



1. 按 `OK` 开始一局三轮游戏。
2. 观看由 3、4、5 张卡片组成的序列，同时大声说出每张卡片的名称。
3. 回忆时按 `UP`、`DOWN` 浏览 6 张卡片，按 `OK` 种下选中的卡片。
4. 拍下最终花园卡、再玩一局，或邀请家人一起记住下一组序列。

状态机与硬件解耦，并由 `tests/test_memory_garden_state.c` 覆盖。卡片播放使用 LVGL
定时器，因此按键回调不会阻塞。应用显示电量，闲置一分钟后调暗背光，三分钟后关闭
背光。

使用以下命令构建这个应用版本：

```bash
FAP_APP=memory_garden ./tools/validate.sh --firmware
```

## 健康边界

天天记一记只是一项娱乐性的认知活动，不是医疗器械、筛查工具、诊断或治疗手段，也不
承诺能够预防或延缓记忆力衰退或痴呆。游戏成绩不能用于判断认知健康状况。如果出现
新发生或持续加重的记忆变化，应咨询合格的医疗专业人士。
