# 嘴硬小豆

一只离线中文语音黄脸小伙伴。摸摸它、逗逗它，或者在旁边说句话：检测到声音时竖起耳朵，等你停下来后显示“思考一下”，随机思考 1.2–3.2 秒，再选一句预设台词回应。创作灵感来自「小狮日记」，本应用为独立开发的非官方作品。

![嘴硬小豆封面](assets/images/mouthy-bean-cover.png)

## 按键

| 操作 | 主界面 | 设置与表情册 |
| --- | --- | --- |
| 上键短按 | 摸摸 | 上一项 |
| 下键短按 | 逗逗 | 下一项 |
| 确定短按 | 请求回应 | 切换、打开或返回 |
| 确定长按 | 打开设置 | 回到小豆 |

双击算一次互动，长按上下键不重复触发。连续摸三次发现偷笑，连续逗五次让它笑崩，交替摸摸和逗逗发现迷糊；连招每次间隔小于七秒。八种表情都在收藏册里提供发现提示。没有每日任务，不玩也没有惩罚。

内置四十句原创、预先合成的中文台词，完全离线播放，字幕与语音匹配。这是固定台词库，不是运行时任意文字转语音。音量分静音、轻声、正常、响亮四档，分别为 0/55/75/90%，默认正常。早期版本的轻声默认会一次性迁移到正常，保留静音。发现记录和设置在独立 NVS 命名空间保存，改动约两秒内合并写入。闲置约 45–75 秒偶尔说一句，两分钟无互动后说一句睡觉台词、闭眼并降低亮度；按键或声音唤醒。调暗背光不代表已验证的低功耗睡眠。

## 声音与隐私

持续约 160 毫秒的声音触发倾听，安静约一秒后进入随机思考。持续噪声超过十五秒时不接话，等待环境安静。环境声、音乐也可能触发。它不识别文字，不接大模型。采用半双工播放：暂不支持人声打断，但按键可打断；播完有 600 毫秒缓冲排空和麦克风屏蔽期，避免自己的声音再次触发。

不保存或上传麦克风录音，不发起网络连接，只在本机保存表情发现记录和设置。音频故障时仍保留表情和字幕；存储故障时仍能玩，设置页会提示。本源码包不包含设备身份、凭据、本地日志、串口回执或预构建固件。

## 构建

请克隆完整仓库：本示例复用根目录 BSP、截图服务和永久 Recovery 引导钩子，不修改它们。激活 ESP-IDF 5.5.3 后运行：

```bash
cd examples/mouthy-bean
./tools/validate.sh
```

完整验证会解析锁定依赖，运行主机状态、音频和界面检查，在独立目录构建并校验合并镜像。输出为 `build/FoloToy-AI-Passport-full.bin`，不会安装到设备。保留 3 MB 应用限制、`0x356000` 身份区、`0x700000` Recovery 和上键五秒引导钩子，不改变根目录应用选择器。

依赖已解析后，可以单独运行：

```bash
python3 tools/test_mouthy_bean.py --ui
./tools/validate.sh --static
./tools/validate.sh --firmware
```

`tools/generate_mouthy_bean_font.py` 使用固定版本字体转换器和现有思源黑体生成字体。`tools/generate_mouthy_bean_audio.py` 可从附带的 WAV 文件重建音频包；加 `--synthesize` 重新合成时需要 macOS Tingting 和 ffmpeg。普通构建不需要在线服务或语音合成。思源黑体遵循仓库中的[字体许可](assets/fonts/OFL-SourceHanSansSC.txt)。
