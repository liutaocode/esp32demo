# 番茄花园（Tomato Bloom）



番茄花园把番茄时钟变成一座小小的专注花园。用户专注时，一颗种子会逐步长成成熟
番茄；完成的每轮专注都会进入可截图分享的收获卡。它用直观的成长反馈呈现专注成果，
不需要账号、信息流、通知或网络连接。

应用提供 15 分钟“快速发芽”、25 分钟“经典开花”和 45 分钟“深度扎根”三档。
普通专注后安排 5 分钟休息，每完成第四颗番茄后安排 15 分钟长休息。进度与收获总数
在本次开机期间保留；首版不会向 Flash 写入数据。

## 操作

- `UP` / `DOWN`：在设置页选择专注时长。
- `OK`：开始、暂停、继续，或进入下一阶段。
- 长按 `OK`：放弃当前计时或跳过休息，但不会丢失已经收获的番茄。

应用界面已完整使用简体中文。专注时画面会自动调暗，但计时仍会继续准确运行，安静地
陪用户完成每一轮专注。

使用下面的命令构建这个应用版本：

```bash
FAP_APP=tomato_bloom ./tools/validate.sh --firmware
```
