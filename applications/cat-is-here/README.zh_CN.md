# 小猫在呢

一只喜欢陪你待着的小猫。叫它过来、摸摸脑袋，或者往房间里滚一个小玩具。
它会眨眼、呼吸、洗脸、伸懒腰、打盹，偶尔叼来一片叶子。摸舒服以后，它会
靠近你多待一会儿。没有饥饿条、家务、惩罚或连续签到。

实际界面代码生成的本机预览，非设备截图

## 三颗按键

| 按键 | 在小房间里 |
| --- | --- |
| 上键 | 摸摸小猫。连续三次、相邻间隔不到八秒，会放心地翻肚皮。 |
| 确认键短按 | 叫小猫过来，随机一种喵叫。 |
| 确认键双击 | 开始三十二秒墨镜小猫舞，配原创节拍；任意按键停舞。 |
| 下键 | 用选好的玩具陪它玩。 |
| 确认键长按 | 打开小窝；再次长按返回。 |

在小窝里，上下键选一项，确认键换一个。可以选四个名字、三种毛色、三种玩具、
轻柔声音或静音，以及桌面或随身模式。最后一项能看看六段共同的小回忆，任意
短按返回。所有选项一开始就能用，不需要解锁。

界面全部使用简体中文。确认键随机喵叫，上键随机呼噜，下键随机玩具声，每组各三种且不会连续重复。双击确认配原创舞曲，静音也会关闭舞曲；只有互动才会响声。
没有语音识别、TTS、麦克风录音、账号或网络连接。

## 安静陪伴

闲置一分钟后屏幕变暗。桌面模式保持低亮度陪伴；随身模式三分钟后关闭背光。
熄屏后的第一次按键只唤醒，不执行动作。小窝闲置三十秒自动回到房间。
名字、毛色、玩具、声音、模式与回忆会保存在本地，一般在操作停止一秒半后保存，
待保存的改动最多延后五秒。保存前断电可能丢失最近的改动。存储故障时仍可继续
当前会话，并显示中文提示。电量不可读取时显示未知，不虚构数值。
