# 成语萌兽



LVGL 主机渲染界面，并非实机照片。

面向能够自主阅读的小学生，建议约 7–10 岁／二至四年级体验的离线成语冒险。
读一个小故事，选择贴切的成语，孵化原创像素伙伴。没有倒计时，也不按速度排名。

## 体验设计

- 三座岛各有八个成语，主题分别为寓言、学习习惯和友谊。
- 每轮四道不重复的题，提供三个打乱位置的选项。优先抽取此前错题，随后抽取
  尚未练过的题，最后才是已经练会的内容。
- 每次作答都展示解释，由孩子读完后按确定继续。首次四题完成后，错题会换一种
  情境再次出现。复习答错不会标记为练会，需要答对或随时返回首页。
- 完成本轮及错题复习后获得伙伴。每座岛按固定顺序解锁两只，没有随机稀有度
  或付费机制，后续完成会再次遇到第二只。结果卡展示首次答对数量，鼓励孩子
  用成语说话，并提示休息。
- 六只萌兽图鉴、已练会和待复习状态保存在本地 NVS，存档状态和故障可见。
  关机前等待“已保存”；不恢复进行中的轮次，但已保存错题会在下一轮优先出现。

产品假设：看得见的收集进度，加上能讲给同学听的小故事，让孩子有分享的理由，
家长也能看懂教育价值。目前没有经过儿童、教师或市场试验验证。题目文案为原创，
并非按教材逐课编排，也不用于判断真正的知识掌握程度。
游戏化学习参考 [Duolingo ABC](https://abc.duolingo.com/how-we-teach)，
解释和回忆练习参考 [Retrieval Practice](https://www.retrievalpractice.org/feedback/)。
这些资料不能证明本应用自身的教学效果。

## 语音讲解

每次答错（含错题复习再次答错）后自动播放普通话 TTS，读出正确成语及其含义。
讲解页上键重听、下键停止；确定继续或长按确定回首页，都会取消旧讲解。
答对不自动播报，但仍可按上键听释义。音频初始化或播放失败时显示语音不可用提示，
文字讲解和答题仍可使用。

全部 24 条讲解用 macOS Tingting 音色、语速 190 离线生成，转换为 16 kHz 单声道，
以约 1.39 MB 的 IMA ADPCM 音频包嵌入固件。工作任务每次解码 512 个采样
（1 KB PCM），独占编解码器操作；任务不持有 UI 指针。离开页面时使旧播放失效，
并投递停止请求，不阻塞 LVGL。修改释义后重新生成：

```bash
python3 tools/generate_idiom_pet_audio.py --synthesize
python3 tools/generate_idiom_pet_audio.py --check
```

WAV、准确朗读文本、音色、采样数和哈希保存在 `assets/music/idiom_pet/`。
固件无需联网或调用 TTS 服务。

## 操作

| 页面 | 上／下键 | 确定键 | 长按确定 |
| --- | --- | --- | --- |
| 首页 | 选择岛屿 | 开始四个故事 | 查看图鉴 |
| 答题 | 选择答案 | 提交答案 | 返回首页 |
| 讲解 | 重听／停止语音 | 读完后继续 | 返回首页 |
| 孵化 | 无操作 | 查看图鉴 | 返回首页 |
| 图鉴 | 上一只／下一只 | 返回首页 | 返回首页 |

闲置一分钟调暗背光，三分钟关闭背光。熄屏后的第一个按键只唤醒屏幕。
电量显示在卡片上方，无法读取时显示 `--%`；按键初始化失败时显示错误。
此版本不需要账号或联网，也不涉及个人数据。

## 实现与构建

`idiom_pet_state.c` 包含独立于硬件的进度和复习逻辑，`idiom_pet_catalog.c` 是题库
的唯一来源。`idiom_pet.c` 绘制 LVGL 界面并处理静态输入队列。按键回调不获取
LVGL 锁，也不写存储。存档工作任务只持有复制的数据，不持有 UI 指针；退出时
先停止接收事件、删除两个界面定时器，再删除屏幕。
NVS 仅使用 `idiom_pet` 命名空间和 `progress_v1` 键；初始化错误不会触发数据擦除。
存储失败仍可在本次开机期间游玩。

激活 ESP-IDF 5.5.3 后，选择构建此应用，默认应用保持原有选择方式：

```bash
FAP_APP=idiom_pet ./tools/validate.sh
```

完整检查运行主机测试，并验证合并镜像 `build/FoloToy-AI-Passport-full.bin`，
包括 3 MB 应用上限、设备身份和永久 Recovery 保护。修改中文文案后重新生成字体：

```bash
python3 tools/generate_idiom_pet_font.py
```

## 仍需实机验收

1. 阅读最长故事和解释，检查字形、布局及按键单次响应；答题时长按确定返回首页。
2. 带错题完成一轮，检查换情境复习和萌兽解锁；听取首次／复习答错的讲解，
   检查上键重听、下键停止、确定／长按确定取消，以及发音、音量、尾音和音频故障。
3. 等待保存完成后断电重启，检查图鉴和待复习内容保留。
4. 检查调暗、熄屏、仅唤醒按键、电量／存储异常、重复进出及三十轮后的堆稳定性。
5. 用小程序安装经过验证的合并固件，在已配置设备上检查开机按住上键五秒进入
   原有 Recovery 的路径。

主机构建或渲染不代表完整硬件验收。后续安装已验证写入、中文首页启动与实机截图。
