# Stack Rush



Line it up. Drop it. Stack one more. Your tower gets taller while your landing zone gets narrower, and every close save makes another try irresistible.

## How to play

1. Use Up or Down to choose Relaxed or Fast mode, then press OK to start.
2. Press OK when the moving floor lines up. Overhangs fall away; the remaining width becomes the next floor.
3. Land three perfect drops in a row to regain some width and aim for 50 floors.
4. Photograph your height, perfect-drop count and playful title, then hand it to a friend to beat.



## Controls and tips

| Screen | Up | Down | OK |
| --- | --- | --- | --- |
| Start | Change mode | Change mode | Start |
| Playing | Pause | No action | Drop |
| Paused | Resume | Return to start | No action |
| Result | No action | Return to mode selection | Retry same mode |

- Relaxed mode helps you find your rhythm; Fast mode tests your timing.
- A complete miss ends the round. Wait for the landing animation before dropping again.
- Each mode keeps its own best height during the current boot. Restarting clears records.
- Everything works offline, without an account or personal-data collection.
- After one idle minute, play pauses and dims; after three, the backlight turns off. The first press wakes only; Up then resumes.

The interface is in Simplified Chinese. See DEVELOPMENT.md for development and validation notes.
