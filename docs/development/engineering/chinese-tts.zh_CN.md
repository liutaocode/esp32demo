# 中文 TTS 移植与验收

口袋朗读员链接上游 ESP-TTS 中文解析器、语音模板对象及 Speex 1.2.1 定点解码器。
不使用语音识别、唤醒词、原 AMR 播放器及其浮点变速路径。内嵌语音库先验证 SHA-256，
再把发音词典交给二进制解析器。

## 运行边界

最长 240 字节的 UTF-8 请求进入单槽覆盖队列，代数计数使旧播放和状态失效。
一个工作任务独占解析器和解码器，不访问 LVGL；按键回调只投递事件。
正常语速（2）按 320 采样、20 毫秒帧流式输出 16 kHz 音频；其他语速解码单个音节，
用整数 WSOLA 变速后按帧写入。语音库先离线调整为原音节的 1.30 倍节奏再压缩，第 2 档无需实时变速。
六档相对制作后声音的倍率为 0.80、0.90、1.00、1.10、1.20、1.30。
帧间和写入间检查取消。没有整句 PCM 缓存、
16 秒时长上限或 Flash 写入。电子书调用方需自行断句、记录阅读位置并提交后续句子，
当前 Demo 没有实现电子书集成。

工作栈为 8 KiB。变速缓冲按验证过的最长记录延迟分配，保留到退出。
停止保留引擎，退出等待工作任务确认，超时保留资源。串口日志区分解析、合成 CPU 时间、
首帧提交、最长帧解码时间、最低堆和栈余量。首帧提交不是声学延迟，DMA 缓冲还会增加延迟；
合成时间不包括扬声器写入阻塞时间。

## 压缩资源

原始小乐库 2,938,039 字节。转换保留发音词典和全部 1,749 条语音记录；该数量不是
汉字覆盖数量，发音、数字归一化、多音词仍由解析器决定。默认 Speex 宽带质量 2 库
为 929,972 字节，其中头部、偏移与词典 171,640 字节。输出 16 kHz、有符号 16 位单声道，
属于有损语音压缩。此前 654 KB 窄带版被用户反馈声音闷；新版保留 16 kHz 采样率及更多
声音细节，主观清晰度仍需试听。当前只接受经过固定哈希验证的宽带库。

不再使用独立语音分区。压缩库属于应用，应用整体仍须小于 3 MiB。设备身份 0x356000
和 Recovery 0x700000 保持不变。后续应用可使用 0x360000–0x700000 的 3.625 MiB
存书；本 Demo 不创建或格式化文件系统。USB 安装后旧语音数据可能仍留在原位置，
但新程序不再读取。

## 复现

来源固定在 `components/esp_tts/upstream.json` 与 `components/speex/upstream.json`。
分发时保留许可文件。原始库留在源码仓库中，仅用作转换输入。
安装 Speex 1.2.1 和 OpenCORE AMR-WB 开发库后运行：

```bash
cc -O2 -Imain tools/tts/repack_voice.c main/tts_tempo.c $(pkg-config --cflags --libs speex opencore-amrwb) -lm -o /tmp/repack-voice
/tmp/repack-voice assets/music/chinese_tts/xiaole.dat /tmp/xiaole-compact.dat 2
cmp /tmp/xiaole-compact.dat assets/music/chinese_tts/xiaole-compact.dat
```

转换器以 16 kHz 解码 AMR-WB，使用整数 WSOLA 调整为 1.30 倍节奏，逐记录独立编码
为 Speex 宽带，并记录编码器前瞻长度用于裁剪，不进行降采样。编码器或库差异可能改变字节；替换语音库时须更新预期哈希，
验证全部记录和真机播放。

在 ESP-IDF 5.5.3 环境运行 `./tools/validate.sh`，检查源码约定、资源哈希、字形覆盖、
语音边界、变速时长/音高、分区 MD5、应用大小、保护区域与内嵌资源内容。
改动中文界面后运行 `python3 tools/generate_chinese_tts_font.py`，`--check` 检查覆盖。
生成器使用固定 `lv_font_conv@1.5.3` 和固定 LVGL 组件内的思源黑体。

## 发布前真机验收

1. 检查冷启动及开机长按 UP 五秒进入 Recovery。
2. 十二组示例分别以 0、2、5 档播放，听辨清晰度、多音词、数字、标点与断续，记录问题。
3. 句中停止、切换示例与语速，再重播。
4. 连续十分钟检查堆、栈及响应。
5. 用主机测试拒绝畸形资源，不擦除设备身份。
6. 投稿前用发布工具抓取新的运行截图。

分别报告 Build、Host tests、Device tests、Unverified。串口自动测试成功不等于
读音正确或主观音质通过。
