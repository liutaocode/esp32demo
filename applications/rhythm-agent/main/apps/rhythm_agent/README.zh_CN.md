# 节奏特工

[English](README.md) | 简体中文

离线三键节奏记忆游戏。先听暗号、看按键亮起，再用同样的按键顺序和停顿复现。
首拍由你自己开始，不用抢一个外部倒计时的起点。

## 玩法

- 新手训练：八道锁，每关三至六拍，基本间隔 650 毫秒，可以无限重试。
- 特工挑战：八道锁，每关四至八拍，基本间隔 500 毫秒，三次失败机会。
- 第三道锁开始可能出现两拍长停顿。演奏不要求组合键或长按，每次按完松开。
- 三键各有不同音高；屏幕按上、下、确定的物理顺序竖排。演奏使用按下事件，
  松开后的单击和双击事件不额外计拍。
- 长按确定暂停，会撤回长按开始时的那一下，包括因此变化的得分和机会。
  继续未完成的尝试会重听同一道锁，不扣机会。
- 反馈页短按确定继续或重试；结算页选择同题再来、递给朋友，或换个任务。
  游戏之外长按确定返回首页。
- 设置提供四档音量、普通话提示开关和两页说明。设置重启后恢复默认；
  仅挑战最高分保存在独立存储空间中。
- 菜单两分钟无操作息屏，第一次按键只唤醒；演奏时不会息屏。

## 评分

训练按键顺序全对即可过关，不限输入时间；节奏准确度作为练习反馈，不阻挡进度。
挑战要求按键全对，平均准确度达到 75。
每一拍独立比较与上一拍的间隔，避免从首拍开始累积误差。误差不超过
110／80 毫秒得 100 分，不超过 220／160 毫秒得 75 分，更大偏差得 25 分；
按错或漏拍得零分，两组阈值分别对应训练和挑战。首拍没有节奏扣分。
按键时间在排队前采集，界面刷新不会改变评分。仅挑战模式中，某一拍相对上一拍
的目标间隔晚于 1100 毫秒则本轮结束。过关后准确度计入总分，最高 800；失败不加分。
四位任务号可在同版本、同模式重赛时生成同样的题目。

## 实现与验证

`rhythm_state.c` 是可独立测试的规则；`rhythm_agent.c` 管理界面和输入队列。
音频以及电量／存储分别运行在不持有界面对象的常驻工作任务中。
仅界面计时器修改控件，输入队列满时暂停，避免漏输入后误判。
退出时关闭输入、移除计时器、取消音频。

三种音符使用定点合成，四段普通话提示离线压缩保存，每次输出 160 个采样并
保留准确的静音间隔。不启用麦克风和网络，不需要账号、密钥或在线语音服务。
声音故障时使用定时灯光示范；存储故障时在内存保留纪录，不擦除存储空间。
固件支持 `FAP_SCREENSHOT_V1`，传输期间冻结截图镜像，避免动画造成撕裂。

先运行 `python3 tools/test_rhythm.py` 和 `python3 tools/test_rhythm_ui.py`，
再激活 ESP-IDF 5.5.3 运行完整 `./tools/validate.sh`。
电脑预览直接运行真实界面代码，检查中文字符、行宽、父级裁切、手势和生命周期，
不代表真机验收。

保留 3 MB 应用上限、身份区域和永久恢复分区。设备仍需验证音色、声画延迟、
实体按键节奏、重启保存、低电量行为，并取得新的串口截图。
