# 见好就收

一个让人纠结“再冲一次，还是现在收下”的掌上小游戏。给笑脸气球充气，
成功后可以收下积分，也可以冒险争取更高奖励。八轮绿区逐渐变窄，适合短局
挑战、和朋友轮流比成绩。设备界面全部为简体中文，无需联网、账号、麦克风或语音。



## 怎么玩

- 按确定开始，在九秒内看准绿区按确定停针。黄色中心命中后，奖励增加一半。
- 成功后，确定再冲一次，下键收下积分。没停在绿区或超时，未收下的积分全部归零。
- 每轮基础奖励为 `100 × 轮数²`，八轮全过自动收分。八轮全部精准，最高可得 30600 分。
- 上键暂停或继续；暂停页下键放弃本轮。结果页确定重来、下键回首页。
  长按确定返回首页；最初按下时仍会执行该页面的普通按键动作。
- 纪录保留至本次关机，退出再进入不会丢失。闲置一分钟调暗、三分钟熄屏，
  第一次按键只唤醒。按键初始化失败时显示提示并禁用操作。

## 构建和验证

激活 ESP-IDF 5.5.3 后，在仓库根目录运行：

```bash
FAP_APP=balloon_rush ./tools/validate.sh
cmake -S tests/balloon_rush_ui -B /tmp/balloon-rush-ui -G Ninja
cmake --build /tmp/balloon-rush-ui
mkdir -p /tmp/balloon-rush-previews
cd /tmp/balloon-rush-previews
/tmp/balloon-rush-ui/preview
```

完整验证包含独立状态测试。单独的真实 LVGL 预览检查字形是否存在、界面无英文、
文字宽度、内容边界、全部轮次、输入队列、唤醒行为及连续五十次退出重进。
预览中的显示、时钟、按键和电池使用模拟数据，不是实机截图。
字体重建命令为 `python3 tools/generate_balloon_rush_font.py`。

本应用没有音频或存储工作线程。按键回调只投递事件；LVGL 定时器管理状态和界面，
复用移动对象、丢弃过期输入，并在删除页面前停止。计时操作期间不读取电池。
命中按最近一次显示的指针位置判断，避免按下后又多走一帧。
保留原有 3 MB 应用限制、身份分区、永久 Recovery 和上键五秒启动钩子。

实体按键延迟、动画流畅度、屏幕可读性、电池休眠体验及小程序安装仍需实机验证。
