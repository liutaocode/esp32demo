# 口袋书架（TTS版）

从原口袋书架复制出的独立应用，加入离线中文朗读。保留 Wi-Fi 传书、书签、阅读进度、
统计、三档字号和五种主题，可从当前页开始听书。内嵌宽带语音库 929,972 字节，
原有书籍分区不变。

## 操作

- 书架：上下选书，确定打开，长按确定进入 Wi-Fi 传书。
- 正文：停止朗读时上下翻页；朗读或暂停模式下，上键增大音量、下键减小音量。
  确定打开菜单，长按确定回书架并停止朗读。
- 菜单：开始/暂停/继续朗读、停止朗读、朗读语速、音量、添加书签、书签列表、阅读统计、
  字号、主题、返回书架。上下滚动列表，确定执行，长按确定回正文。
- 暂停后继续会从当前句重新开始，避免漏掉被打断的半句话。朗读会自动跨页继续。
  切换语速会暂停，选“继续朗读”后使用新语速。
- 朗读时顶栏和底部状态栏同样自动收起。调音量时短暂显示音量，随后再次自动收起。
- 此版本关闭翻页音效。
- 开机长按 UP 五秒进入永久 Recovery。

手机上传 UTF-8 `.txt` 的方法与原阅读器一致。语音根据书籍正文即时合成，不是预录句子。
长文本按标点或 UTF-8 字符边界分段。生僻字、多音词可能存在读音问题，不保证任意语言覆盖。
首次初始化会加入“朗读体验”“唐诗选读”“宋词选读”三本测试书；升级时补充缺少的诗词测试书，保留已有内容与进度。

## 构建与存储

使用 ESP-IDF 5.5.3，目标为 8 MB Flash、无 PSRAM 的 ESP32-C3 设备：

```bash
source /path/to/esp-idf-v5.5.3/export.sh
./tools/validate.sh
idf.py -p PORT flash
```

应用维持在 3 MiB 安装上限内。`books` 保持偏移 `0x360000`、大小 `0x3A0000`，
设备身份和 Recovery 地址不变。分段 USB 烧录不覆盖书籍数据。与原阅读器一样，
首次挂载失败时会格式化文件系统，因此迁移前备份已有存储。构建和设备备份不提交到 Git。

单一任务独占语音编解码器；书架工作任务读取文件、提交句子，LVGL 只绘制快照。
进入 Wi-Fi 传书前释放朗读资源，传书结束后重新初始化，给内部 RAM 留出空间。
应用作为唯一前台界面运行，直到重启。

## 源码与许可

书架功能复制自已有口袋书架，TTS 复用已测试的中文朗读 Demo。
应用整合代码遵循仓库许可，分发时保留 ESP-TTS、Speex 和字体许可；
部分上游语音引擎组件以预编译库提供。

主机测试覆盖分页、文件名、菜单状态、断句、暂停游标和全部语音解码。
固件大小、保护区验证与真机播放、自动翻页、传书及内存验证分别报告。

## 音量调节

在阅读菜单选中“音量”并按确定，进入调整状态，上下键加减音量，确定或长按确定
结束调整；菜单显示当前百分比。朗读时按上下键，会在正文上方显示音量进度条，
约 2.5 秒后与阅读顶栏、状态栏一起自动消失。
