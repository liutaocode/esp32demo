# 再叠一层



看准、落下、再叠一层。楼层越叠越高，剩下的落点却越来越窄；每一次刚好接住，都让人想再试一次。

## 怎么玩

1. 用上、下键选择「轻松叠叠」或「极速挑战」，按确定开始。
2. 看准移动楼层，按确定落下。没有对齐的部分会掉落，剩余部分成为下一层。
3. 连续三次精准落点，可以恢复一部分宽度，争取一路叠到 50 层。
4. 结束后拍下楼高、精准次数和趣味称号，把设备递给朋友挑战。



## 按键与小贴士

| 页面 | 上键 | 下键 | 确定键 |
| --- | --- | --- | --- |
| 开始页 | 切换模式 | 切换模式 | 开始 |
| 游戏中 | 暂停 | 无操作 | 落下 |
| 暂停中 | 继续 | 返回开始页 | 无操作 |
| 结果页 | 无操作 | 返回模式选择 | 同模式再来一局 |

- 轻松模式适合找手感，极速模式更考验反应。
- 完全没有接住就会结束；别急着连按，等待落地动画完成。
- 两种模式分别保留本次开机的最高纪录，重启后清空。
- 全程离线，不需要账号，不收集个人信息。
- 闲置一分钟自动暂停并调暗，三分钟关闭背光；第一次按键只唤醒，再按上键继续。
