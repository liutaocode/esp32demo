# 口算小火车

全中文、离线、单人玩的口算小游戏。小火车带着十颗星出发，首次答对一题就点亮一颗。每趟十道不重复算式；不倒计时、不按速度加分、不扣生命，也不自动跳题。

## 操作与难度

- 上下键选择难度、三个答案之一或结算选项。确定键开始、作答或继续。长按确定回首页，会放弃当前一趟。
- 四档范围：十内加减、二十内加减、百内加减、乘除口诀。乘除使用一至九的因数；这些是练习范围，不承诺对应所有教材年级。
- 每趟两种运算各五题，顺序随机，算式不重复。减法不出负数，除法都能整除，三个答案互不重复且仅一个正确。
- 答后都显示完整正确算式；答错还会显示刚才所选答案，按确定才继续。
- 到站后可选「再来一趟」「错题再练」「更换难度」。没有错题时自动跳过灰色复习项。
- 错题再练只练答错的算式，重新排列答案，答对便移出错题。仍未订正的题可以继续练。订正不会改变原始成绩或最高连对。
- 四档最佳成绩分别记录，仅保留至本次关机。开始新一趟会清除上一趟及其错题。不包含永久进度、联网、麦克风或 TTS。
- 闲置一分钟调暗，三分钟熄屏，第一次按键仅唤醒，不作答、不离开当前页。电量读取失败显示占位；按键不可用时显示中文提示。

## 实现与验证

纯状态逻辑在 `math_train_state.c`。按键回调只投递带时间戳的事件，由 LVGL 定时器更新界面；跨页面的过期事件与连击会被丢弃。进入和退出需持有 BSP 的 LVGL 锁；退出先禁用输入，再删除两个定时器，最后删除页面，没有后台任务访问界面。

18 像素中文子集与 28 像素算式字体来自思源黑体（SIL OFL），不依赖表情或图标字库。保留共同的像素蓝天、标题牌、描边纸面和草地；火车采用原创几何图形。

```bash
python3 tools/generate_math_train_fonts.py --check
cc -std=c11 -Wall -Wextra -Werror -Imain/apps/math_train tests/test_math_train_state.c main/apps/math_train/math_train_state.c -o /tmp/test_math_train_state
/tmp/test_math_train_state
cmake -S tests/math_train_ui -B /tmp/math-train-ui
cmake --build /tmp/math-train-ui -j8
# 在临时输出目录运行 preview，会写出 PPM 界面预览。
# 激活 ESP-IDF 5.5.3 后：
FAP_APP=math_train ./tools/validate.sh
```

主机测试检查十二万道随机算式、运算比例、唯一选项、确定性种子、计分、错题订正和菜单循环。真实 LVGL 测试另检查四千题的答题及反馈页面，包括缺字、英文字母、文字宽度、边界、同级文字重叠、待机唤醒、按键连击、外设不可用与五十次退出重进。
