# 口袋捞鱼

全中文、离线、按回合推进的摸鱼收藏小游戏。
查看带图介绍与审核物料。

## 怎么玩

每趟把九种鱼和三次浪随机打乱，不放回。短按确定捞一次，下键把鱼篓
收进鱼册。第一次浪没有损失；第二次浪结束本趟，冲走尚未收好的鱼。
捞齐九种鱼自动收好，满分 29 分。屏幕直接显示剩余鱼、浪和下一次抽取
的准确概率。没有倒计时、反应测试、体力、付费或联网。

上键打开鱼册；上下翻页、确定返回。长按确定回首页，不丢弃这一趟，
再按确定继续。双击只算一次动作，快速连续输入会合并，避免误多捞一次。

每种鱼最多记录 999 条，累计收下 1、5、20 条分别得到铜章、银章、金章。
最高单趟得分和最多 9999 趟的累计次数保存在本机。关机前请等待“鱼册已保存”。
未收下的一趟可以放置、回首页后继续，但**断电后不会保留**。
存储异常会显示中文提示，不会主动擦除已有 NVS 数据。

闲置 30 秒调暗，90 秒熄屏，唤醒的第一次短按或长按只亮屏。
适合安全停车休息或乘客使用，不面向驾驶员等红灯时操作。没有语音和麦克风功能。

## 实现与验证

纯状态模型负责不放回鱼池、收鱼与浪的判定、收藏计数和 24 字节版本化存档。
按键回调只做零等待入队，LVGL 定时器消费输入。应用生命周期的独立工作任务
负责 NVS，不访问任何界面对象。退出前关闭输入、删除定时器，再删除页面。
没有新增 BSP 逻辑、依赖、引脚、分区或 Recovery 改动。
保留已有 `FAP_SCREENSHOT_V1` 服务，供之后的实机截图使用。

```sh
# 先激活 ESP-IDF 5.5.3。
FAP_APP=pocket_pond ./tools/validate.sh
cmake -S tests/pocket_pond_ui -B build/pocket-pond-ui
cmake --build build/pocket-pond-ui -j8
(cd projects/pocket-pond/assets && ../../../build/pocket-pond-ui/preview)
```

主机测试覆盖 20000 个洗牌种子、得分、收鱼与失败、概率、存档校验和计数上限。
实际 LVGL 页面测试覆盖字体缺字、中文界面、文字宽度、屏幕和面板边界、文字行重叠、
鱼册变体、连续输入、回首页继续、待机唤醒、电量/按键/存储异常和退出。
构建通过不代表实机验收；实体键、显示色彩、长时间待机、断电存档和 USB 截图仍需上机检查。
